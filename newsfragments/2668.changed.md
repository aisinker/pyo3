The `dynamic-loading` feature requires Rust 1.99 or newer ([#2668](https://github.com/PyO3/pyo3/issues/2668)), because it defines C variadic functions to provide the variadic entries of the Python API. Enabling it on an older compiler is reported as an error by the build script, and it is the only thing which needs the newer compiler: the minimum supported Rust version of `pyo3` and `pyo3-ffi` is otherwise unchanged at 1.85, so the version gates for older compilers (the `cfg_select` polyfill and the `CStr::from_bytes_with_nul` fallback) are kept. `PyUnstable_Code_GetExtra`, `PyUnstable_Code_SetExtra` and `PyUnstable_Eval_RequestCodeExtraIndex` are resolved under the private names they have before Python 3.12, and a warning message which UTF-8 cannot represent is written in its `backslashreplace` form.
